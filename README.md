## 🚀 Featured Project

### 📚 **Book E-Marketplace** — Bachelor's Final Year Project (FYP)

> A real-time **C2C e-commerce platform** for secondhand textbook trading between UiTM students, replacing informal WhatsApp and Facebook group trading with role-based access, price negotiation, and an analytics dashboard.

| Aspect | Details |
|--------|---------|
| 🏗️ **Architecture** | MVC pattern with 3 user roles (Student, Staff, Admin) |
| 🛠️ **Tech Stack** | HTML5 · CSS3 · JavaScript · Firebase Realtime Database · Firebase Authentication |
| 📊 **Dashboard** | 8 interactive Chart.js visualizations (sales, revenue, warranty resolution) |
| 💡 **Key Features** | Price negotiation · 7-day warranty and dispute resolution · Real-time sync · Transaction tracking |
| ✅ **Testing** | **100%** pass rate on 22 functional test cases · **95%** task completion rate in usability testing · **83/100** System Usability Scale score |
| 🔗 **Repository** | [View on GitHub](https://github.com/qieyl345/Web-Based_Book_E-Marketplace_with_Data_Visualization_for_Uitm) |

**What I built and learned:**
- Designing role-based access across three user types
- Real-time data synchronization with Firebase Realtime Database
- Turning raw sales data into admin dashboards with Chart.js
- Planning and running functional and usability tests (22 test cases, SUS questionnaire)
